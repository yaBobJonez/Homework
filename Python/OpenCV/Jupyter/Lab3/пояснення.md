## 1️⃣ Нормалізація зображення

```python
import cv2
import numpy as np

image = cv2.imread('input.png').astype(np.float32) / 255.0
```

* OpenCV зчитує зображення як uint8 `[0,255]`.
* Для обробки через NumPy зручно працювати з float `[0,1]`.

---

## 2️⃣ Перетворення у grayscale

```python
gray = 0.299*image[:,:,2] + 0.587*image[:,:,1] + 0.114*image[:,:,0]
```

* `image[:,:,2]` — червоний канал, `[:,:,1]` — зелений, `[:,:,0]` — синій.
* Зважене середнє каналів для відтінків сірого.

---

## 3️⃣ Негатив зображення

```python
negative = 1.0 - image
```

* Інверсія кольорів: світле → темне, темне → світле.

---

## 4️⃣ Яскравість і контраст

```python
brightness = 0.1
contrast = 1.2
bright_contrast = np.clip(contrast * image + brightness, 0, 1)
```

* `np.clip()` обмежує значення пікселів у межах `[0,1]`.
* Можна швидко підвищити яскравість і контраст.

## 5️⃣ Корисні функції NumPy для зображень

| Функція                                 | Приклад                                        | Що робить                                      |
| --------------------------------------- | ---------------------------------------------- | ---------------------------------------------- |
| `np.flip(image, axis=1)`                | `flipped = np.flip(image, axis=1)`             | Віддзеркалює зображення горизонтально          |
| `np.rot90(image)`                       | `rotated = np.rot90(image)`                    | Обертає на 90°                                 |
| `np.mean(gray)`                         | `avg_brightness = np.mean(gray)`               | Середнє значення пікселів (яскравість)         |
| `np.where(gray>0.5,1,0)`                | `mask = np.where(gray>0.5,1,0)`                | Умовна заміна елементів                        |
| `np.hstack((image, negative))`          | `combined = np.hstack((image, negative))`      | Об’єднання зображень по горизонталі            |
| `np.vstack((image, negative))`          | `combined = np.vstack((image, negative))`      | Об’єднання по вертикалі                        |
| `np.linalg.norm(vector)`                | `length = np.linalg.norm(vector)`              | Довжина вектора (корисно для трансформацій)    |
| `np.linspace(0,255,320,dtype=np.uint8)` | `grad = np.linspace(0,255,320,dtype=np.uint8)` | Рівномірно розподілені числа (градієнт, масив) |

## 6️⃣ Створення відео з фреймів (Linux контейнер)

```python
import os
import subprocess

os.makedirs("frames", exist_ok=True)

# Генеруємо 30 кадрів
for i in range(30):
    frame = np.zeros((240,320,3), dtype=np.uint8)
    frame[:,:,0] = np.linspace(0,255,320,dtype=np.uint8)
    frame[:,:,1] = i*8
    frame[:,:,2] = 255 - frame[:,:,0]
    cv2.imwrite(f"frames/frame_{i:03d}.png", frame)

# Збираємо відео через ffmpeg
subprocess.run([
    "ffmpeg", "-y",
    "-framerate", "10",
    "-i", "frames/frame_%03d.png",
    "-c:v", "libx264", "-pix_fmt", "yuv420p",
    "output.mp4"
])
```

* `subprocess.run([...])` запускає команду у системі.
* Використовуємо `ffmpeg` для збору кадрів у mp4.
* `-y` перезаписує файл без запиту.

from IPython.display import Image, clear_output
import time

cap = cv2.VideoCapture("output.mp4")

while cap.isOpened():
    ret, frame = cap.read()
    if not ret: break
    _, buf = cv2.imencode('.jpg', frame)
