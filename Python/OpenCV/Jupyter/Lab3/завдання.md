Завдання для самостійної роботи: “Обробка об’єктів на відео через NumPy”

**Мета:** Практично застосувати NumPy для обробки зображень, розмітки відео та генерації нового відео з ефектами на об’єктах.

---

## # Кроки завдання

1. **Переглянути датасет**

   * Шлях: `COCO`
   * Вміст: відео та JSON/COCO розмітка кадрів.

2. **Зчитати відео та розмітку**

   * Розмітка: COCO формат (`annotations.json`)

3. **Нанести розмітку на кадри**

   * Для кожного кадру знайти відповідні бокси (bounding boxes) з розмітки.
   * Використати ваш клас `RectangleTool`.
   * Додати функцію зчитування з json

4. **Вирізати бокси**

   * Для кожного кадру та об’єкта:

     ```python
     x1, y1, x2, y2 = box_coords
     roi = frame[y1:y2, x1:x2]
     ```
   * Зберігати всі бокси у список для обробки.

5. **Накласти ефект через NumPy**

   * Наприклад:

     * Негатив: `roi = 1.0 - roi/255.0`
     * Збільшення контрасту: `roi = np.clip(roi*1.2, 0, 1)`
     * Градієнт/фільтр: `roi[:,:,0] = np.linspace(0,255,roi.shape[1])`
   * Можна застосувати різні ефекти до різних класів об’єктів.

6. **Склеїти бокси у відео**

   * Об’єднати бокси по вертикалі або горизонталі:

     ```python
     combined = np.hstack(list_of_rois)
     ```
   * Зберегти нове відео через:

     ```python
     import cv2
     out = cv2.VideoWriter('output_boxes.mp4', cv2.VideoWriter_fourcc(*'mp4v'), fps, (width,height))
     out.write(combined)
     out.release()
     ```

7. **(Опційно) Програвати результат у Jupyter**

   ```python
   from IPython.display import Video
   Video("output_boxes.mp4", embed=True)
   ```
